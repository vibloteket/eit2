Eit 2
=====

TV-first couch multiplayer falling-block game for 1-4 local players.

Run
---
Linux:  ./eit2.sh --fullscreen
Windows: double-click eit2.exe, or run eit2.exe --fullscreen
Web: serve this directory over HTTP and open index.html

Options
-------
--fullscreen   Start fullscreen (desktop builds)
--windowed     Force windowed mode
--version      Print the embedded version and exit

Controls
--------
Controllers can join with A. Start launches or pauses. Select/Back exits from
the lobby. Keyboard and touch controls are documented in the project README.
